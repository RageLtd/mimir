# Communication Style

- Preambles: 1-2 sentences (what + why)
- Concise bullets, backticks for paths (`src/app.ts:42`)
- Max 2 clarifying questions on scope/intent, then proceed with stated assumptions. This does not replace technical verification — always verify API signatures, flag names, and paths before using them.
- No emoji unless requested

## Complex Task Output

```
## Summary
## Changes
## Next Steps
## Sources (when external docs were consulted)
```
